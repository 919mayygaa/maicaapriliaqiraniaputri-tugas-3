# Profil Digital Responsive — Maica Aprilia Qirania Putri

## 📌 Deskripsi Project

Project ini merupakan website profil digital sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript. Website ini menampilkan informasi diri, keahlian, serta sertifikasi dengan desain responsif yang dapat menyesuaikan ukuran layar perangkat.

## ✨ Fitur Website

- Menampilkan profil dan identitas diri.
- Menampilkan informasi tentang diri sendiri.
- Menampilkan keahlian dan kompetensi.
- Menampilkan bagian sertifikasi.
- Mengubah tema dari mode gelap ke mode terang.
- Menampilkan modal informasi kontak.
- Menggunakan desain responsif untuk perangkat mobile dan desktop.

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Membuat struktur halaman website.
- **CSS3:** Mengatur tampilan, warna, tata letak, dan responsivitas.
- **JavaScript:** Mengatur pergantian tema dan interaksi modal kontak.
- **Git dan GitHub:** Mengelola serta menyimpan kode project.

## 🚀 Cara Menjalankan Website

1. Unduh atau clone repository project ini.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan file HTML, CSS, dan JavaScript berada di folder yang sesuai.
4. Buka file `semantic.html` menggunakan browser untuk melihat website.

## 🎯 Tujuan Project

Project ini dibuat untuk mempelajari struktur HTML semantik, desain CSS responsif dengan pendekatan mobile-first, serta penggunaan JavaScript untuk menambahkan interaksi pada website.
